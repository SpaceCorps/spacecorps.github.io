# SpaceCorps

SpaceCorps Technology AB builds a space MMO, the Space3d engine it runs on, an open-source business platform and a fleet of command-line tools. Most of it is open source.

## Products

| Product | What it is | Status | Links |
| --- | --- | --- | --- |
| SpaceCorps 2027 | Free-to-play space MMO for macOS, Windows, Linux, Android and the browser | Released, version 0.5.9 | [Download](https://play.spacecorps.tech/), [browser](https://web.spacecorps.xyz/) |
| Space3d | Cross-platform game engine in Rust (native, web, mobile), Apache-2.0 | Public repository | [space3d.dev](https://space3d.dev/), [source](https://github.com/SpaceCorps/Space3d) |
| obop | Open-source business OS in Rust and Vite+, Apache-2.0 | Early code | [obop.dev](https://obop.dev/), [source](https://github.com/SpaceCorps/obop) |
| Space3d-Molecular | Molecular dynamics (spacemd) and electron emission (spaceemit) | Docs repository, hosted API | [docs](https://github.com/SpaceCorps/Space3d-Molecular), [case study](https://spacecorps.tech/blog/getelec-spaceemit.html) |
| Swindle | Trading game for Mac with on-device AI NPCs | Release 0.1.0 | [releases](https://github.com/SpaceCorps/swindle-releases/releases) |

## Open source

24 MIT-licensed Rust command-line tools (Sliplane, Cloudflare, Spaceship, Loopia, Namecheap, Storage, Exa, Firecrawl, Tic, Gmail, Notify, Bugsink, HeyReach, Reddit, Twitter/X, LinkedIn, YouTube, TikTok, Product Hunt, Stack Overflow, Samsung Art Mode, GitHub Issue Importer, Claude Sessions, open-apply), plus DiskLens, open-apple-models, open-android-models, open-accounting-sweden, open-browser, open-agents and open-glass. Everything is on [github.com/SpaceCorps](https://github.com/SpaceCorps).
