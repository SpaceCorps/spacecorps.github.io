obop: one business, one platform

SpaceCorps · 16 October 2026 · Product

obop is a business platform we are building to be open source: CRM, sales, invoicing, contacts and more on one data model, with the permissions and privacy to trust both people and AI agents. It is early code, the repository is not public yet, and you can already get a hosted instance at obop.dev, free while in beta.

What it is

Sales, purchasing, stock, invoicing, accounting and more as modules on one shared data model, so there is one record of every customer, product and euro. Odoo is our functional reference; obop re-implements its concepts clean-room, and changes the parts its users complain about most: one open edition, a free generated API, and upgrades that are a product feature.

Built for people and agents

  • One command layer: REST, MCP and the CLI all go through the same dispatcher, so permissions, masking and approvals apply identically everywhere.
  • Generated API: REST with OpenAPI and an MCP server for every model, on every plan.
  • Scoped agent tokens: a token can only narrow what its owner may do; personal data is masked (or hidden) by default when an agent reads it.
  • Agents draft, humans post: actions that matter can require approval.

Simple to run

The backend is Rust and the frontend is built with Vite+. Locally it runs on SQLite; for deployment it is one binary plus PostgreSQL. Business logic ships as installable declarative packages, and the backoffice renders itself from the model metadata, including a Customize app for themes, apps and modules.

Where it stands. obop is early code, not a finished Odoo replacement. It starts with a fraction of Odoo's breadth (contacts, products, CRM, sales and invoicing today), and we make no speed claims until we have a benchmark to show.
