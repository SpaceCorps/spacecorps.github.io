# SpaceCorps Developer Portal

SpaceCorps engineers high-performance, native Rust command-line tools, autonomous agent interfaces, and decentralized systems. Every CLI in our fleet is built with Rust 2024, compiled to a standalone static binary, and features sub-3ms cold-start latency, structured YAML/JSON outputs, OS keystore secrets integration, and 100% offline TCP mock test coverage.

## Universal Engineering Standards

1. **Sub-3ms Cold Start**: Standalone static binaries compiled with Rust 2024 and optimized release profiles.
2. **Deterministic Agent Protocol**: Human-friendly YAML on `stdout` by default; strict JSON with `--json` for LLM tool calling.
3. **OS Keystore Encryption**: Secure credential storage using macOS Keychain, Linux Secret Service, and Windows DPAPI.
4. **Offline TCP Mock Integration Tests**: Comprehensive in-process TCP mock suites ensuring 100% test reliability with zero network dependencies.
5. **Open Source**: 100% free under the MIT License.
