Privacy

This site collects nothing about you.

This website

spacecorps.tech sets no cookies, runs no analytics or trackers and loads no third-party scripts, fonts or images. Our web server keeps standard request logs (address, time, page) for security and operations, which we do not share.

The game

SpaceCorps 2027 has its own privacy policy, which covers the client, the game server and the download site: play.spacecorps.tech/privacy. It is operated by SpaceCorps Technology AB.

Our command-line tools

They send no telemetry. API credentials you give a tool are stored in your operating system's keystore (macOS Keychain, Linux Secret Service or Windows DPAPI) and are sent only to the service the tool talks to. Each tool's repository documents what it contacts.
