Privacy Policy & Security Standard

Last updated: September 24, 2026. This Privacy Policy details the data protection practices, telemetry posture, and credential handling mechanisms enforced across all software released by SpaceCorps.

1. Strict Zero-Telemetry Commitment

Every binary published by SpaceCorps contains zero telemetry, zero usage tracking, and zero analytical beacons. We firmly believe that developers' terminal commands and autonomous agent tool calls are private. SpaceCorps operates no tracking servers and collects no IP addresses, logs, execution counts, or device identifiers from any of our CLI tools.

2. Cryptographic Local Keystores

API keys, bearer tokens, and credentials are never stored in plaintext configuration files by default. Each SpaceCorps CLI integrates natively with host operating system credential vaults:

  • macOS: Native Apple Keychain Services API via /usr/bin/security.
  • Linux: freedesktop.org Secret Service API via secret-tool and DBus.
  • Windows: Microsoft Data Protection API (DPAPI) encrypted under user credentials.

3. Direct Outbound Communications

When you run a command against an upstream provider (e.g. Sliplane, Cloudflare, Apify, Exa, Firecrawl), the binary makes direct HTTPS requests from your local machine to the official target provider's API. No proxy or relay infrastructure is operated or inserted by SpaceCorps.

4. Website Privacy

The spacecorps.github.io domain and documentation pages are statically hosted on GitHub Pages. They contain no tracking pixels, analytics cookies, or external surveillance scripts. Standard server access logs are handled directly by GitHub in accordance with the GitHub Privacy Statement.
