Space3d

A cross-platform game engine in Rust for native, web and mobile. Deterministic simulation, headless rendering and golden-screenshot tests make it a loop an AI agent can verify. It runs SpaceCorps 2027.

05 / How we build

Small team. Strong defaults.

01

Rust first

Services, the engine and the tools are Rust. The web is TypeScript on Vite+.

02

Agent-friendly

Every CLI speaks plain text for people and --json for agents. Engines come with headless test loops.

03

Everything in a container

If it runs, it ships as a Docker image. This site is one: Caddy serving static files.

04

Open by default

Source, releases and decisions are public. No cookies or trackers on our sites.
