Products

What we ship today. Status is stated plainly on each card.

Game

SpaceCorps 2027

A free-to-play space MMO: fly for a corporation, hunt aliens with your clan and climb the season ranking. Desktop clients for macOS, Windows and Linux, an Android build and a browser build, all on our own engine. Version 0.5.9.

Engine

Space3d

A cross-platform game engine in Rust for native, web and mobile, with a Claude Code integration for agent-driven development. Apache-2.0.

space3d.devSource
Business software

obop

One business, one platform: an open-source business OS in Rust and Vite+, with accounting, invoicing, sales, CRM and stock as modules on one data model. Apache-2.0. Early code, not a finished product.

obop.devSource
Simulation

Space3d-Molecular

Molecular dynamics (spacemd) and thermal-field electron emission (spaceemit) on Space3d. Public API docs, input formats and examples.

Game

Swindle

Trading game for Mac with on-device AI NPCs: 100 days to hit the quota in a bazaar of LLM-driven characters. iPhone and iPad are planned. Release 0.1.0.
