Contact & Support

We welcome bug reports, pull requests, agent integration feedback, and architectural discussions across our entire portfolio of native Rust tools. Below are the official communication channels for SpaceCorps.

Support & Issue Tracking

  • GitHub Organization: Explore repositories, open issues, and check out releases at github.com/SpaceCorps.
  • Repository Issue Trackers: For tool-specific bug reports or feature requests, open an issue directly in the respective repository:
    • Sliplane CLI Issues
    • Exa CLI Issues
    • Firecrawl CLI Issues
    • Cloudflare CLI Issues
    • Spaceship CLI Issues
    • Or any of our 22 project repositories on GitHub
  • Direct Contact: Reach out via email at contact@spacecorps.dev.

Security Reporting

If you discover a security vulnerability in credential handling, OS keystore integration, or networking code in any SpaceCorps CLI binary, please report it responsibly via GitHub Private Vulnerability Reporting on the target repository or by emailing security@spacecorps.dev.

Upstream Service Disclaimers

SpaceCorps CLI tools interface with third-party cloud platforms and APIs (such as Sliplane, Cloudflare, Spaceship, Apify, Exa, Firecrawl, Loopia, and Bugsink). For issues related to third-party API availability, service outages, billing, or account status, please consult the respective platform's status page and official documentation.
