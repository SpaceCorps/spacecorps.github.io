About SpaceCorps

SpaceCorps Technology AB is a small Swedish software company. We build games, a game engine, business software and developer tools, mostly in Rust.

What we make

  • SpaceCorps 2027, a free-to-play space MMO for macOS, Windows, Linux, Android and the browser.
  • Space3d, the Rust game engine the game runs on, also used for molecular simulation.
  • obop, an open-source business platform in early development.
  • Open-source tools: 24 Rust command-line tools and several libraries, all on GitHub.
  • Custom physics software for researchers; see the spaceemit case study.

How we work

A small team plus AI agents. Rust for services and performance-critical code, TypeScript on Vite+ for the web, everything shipped as containers. Every product site uses the same design system.
