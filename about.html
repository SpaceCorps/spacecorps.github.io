Mission & Origins

Developer tooling has grown needlessly complex and slow. Managed runtime interpreters (.NET, Python, Node.js) add hundreds of megabytes of disk overhead and hundreds of milliseconds of initialization latency. When autonomous AI agents fan out and invoke dozens of CLI commands concurrently to research, deploy, and verify infrastructure, these startup delays compound into sluggish agent performance.

Originally prototyped as .NET global tools by developer Niels Bosma, the entire fleet was acquired and completely re-architected in 2026 into native Rust 2024 binaries under the SpaceCorps organization. Each tool preserves the full original git history while upgrading the implementation to modern systems engineering standards: single static binaries, blocking HTTP with rustls, native operating system keystore encryption, and structured YAML/JSON outputs.

The SpaceCorps Engineering Tenets

  • Native Rust 2024: Zero garbage collection pauses, memory safety guarantees, and sub-3ms execution startup for instantaneous terminal response.
  • Deterministic Agent Protocols: Human-readable YAML on standard output by default, strict structured JSON when passed --json, and machine-readable error envelopes on standard error with stable exit codes (1 to 7).
  • Cryptographic OS Keystores: No unencrypted tokens or plaintext credentials in home directories. Keys are securely stored via macOS Keychain Services, Linux Secret Service, or Windows DPAPI.
  • 100% Offline TCP Mock Integration Testing: Every CLI command is verified by in-process TCP mock servers, ensuring zero flaky network tests and rock-solid deterministic CI/CD pipelines.
  • Autonomous Agent Discovery: Every tool publishes dedicated llms.txt manifests, agent cards, and embedded <binary> agent-readme commands so AI agents can self-configure and operate independently.
